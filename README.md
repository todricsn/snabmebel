# Снабмебель

Статический сайт: 12 страниц HTML, локальные стили, скрипты, изображения и шрифт. Сборка и установка зависимостей не нужны.

## GitHub Pages

1. Откройте **Settings → Pages**.
2. В **Source** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.

Главная страница `index.html` находится в корне. Файл `.nojekyll` оставляет сайт обычной статикой. Относительные ссылки поддерживают адрес проекта `/snabmebel/`.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Локальный просмотр

Из корня репозитория:

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080/`.

## Текущее состояние

Это версия для согласования. Форма готовит текст заявки локально; автоматическая отправка и загрузка файлов не подключены. Индексация закрыта через `noindex` и `robots.txt`. Перед запуском рабочего сайта нужно подключить получение заявок, подтвердить данные компании, добавить реальные проекты и настроить индексацию под основной домен.

Лицензии шрифта, контактных иконок и GSAP находятся в `assets/`.

## Анимации

Общий локальный GSAP 3.15.1 управляет вступлением и появлением блоков на всех страницах. Заставка показывается один раз за сессию вкладки; пользовательское взаимодействие завершает её сразу. Учтены reduced motion, возврат назад и работа без JavaScript.

Проверка поведения движка без дополнительных зависимостей: `node tests/site-motion.test.cjs`.
